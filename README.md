Название: YLedControl

Пользовательская библиотека на языке Python для управления
умной светодиодной лампой Yeelight YLDP02YL через локальную сеть.

Описание:
Данная библиотека разработана в рамках выпускной квалификационной
работы на тему "Разработка пользовательской библиотеки Python для
встроенных приложений".

Библиотека представляет простой программный интерфейс для управления
лампой Yeelight YLDP02YL без необходимости самостоятельной работы
с сетевыми сокетами, JSON-командами и протоколами взаимодействия
устройства. Все основные операции управления реализованы в виде
удобных методов класса.

Управление лампой осуществляется через локальную сеть по протоколу
TCP с использованием технологии Yeelight LAN Control.

Основные возможности:
- подключение к лампе по IP-адресу;
- включение и выключение устройства;
- переключение текущего состояния лампы;
- изменение яркости освещения;
- изменение цветовой температуры;
- управление цветом с помощью RGB и HSV-кодов или с указанием названия цвета;
- получение текущих параметров устройства;
- сохранение настроек по умолчанию;
- обработка ошибок подключения и передачи команд.

Требования:
- Python 3.13 и выше;
- лампа Yeelight YLDP02YL;
- включенный режим LAN;
- подключение компьютера и лампы к одной локальной сети

Пример использования находится в файле test.py

Поддерживаемые функции:
- power_on - включение лампы
- power_off - выключение лампы
- power_switch - переключение состояния
- brightness - изменение яркости
- temperature - изменение цветовой температуры
- set_rgb - изменение цвета через RGB
- set_hsv - изменение цвета через HSV
- get_settings - получение текущих параметров
- set_default - сохранение настроек по умолчанию

Назначение проекта:
Проект предназначен для изучения принципов взаимодействия 
программного обеспечения с IoT-устройствами в рамках курса
встроенных приложений. Библиотека может использоваться в
учебных проектах, лабораторных работах и демонстративных 
примерах по программированию на языке Python.
